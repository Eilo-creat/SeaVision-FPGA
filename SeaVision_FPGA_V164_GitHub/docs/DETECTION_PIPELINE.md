# 目标检测数据流

## 海胆候选检测

RGB 视频流 → 亮度/色度筛选 → 4 倍采样 → RLE 相邻行候选区域合并 → 外接框及四维特征提取 → 定点线性 SVM 辅助判别 → 面积/形状/ROI/跨帧确认 → HDMI OSD。

四维特征为 `rough`、`span`、`asym`、`pixels`。实际四维判别函数：

`f(x) = 19 * rough + 13 * span - 189 * asym + 2 * pixels - 1121`

`f(x) >= 0` 是候选 SVM 条件之一，不是唯一检测准则。保存的 15 维相关模块未接入当前有效四维判别通路。

## 粉色物块

颜色阈值与区域几何定位，逐帧计算位置与边界框；不使用上述海胆四维 SVM。

## 判别显示

SVM 显示为正向余量缩放值，不是 0–10 分准确率。`P` 为实验性估计，不构成经独立验证的分类准确率。
